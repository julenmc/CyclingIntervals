# CyclingIntervals

## Description
**CyclingIntervals** is a demo application that provides a graphical interface for viewing and analyzing intervals detected in cycling sessions. The application allows you to import cycling activity files (`.fit` format), process the data, and graphically display the identified training intervals.

> [!WARNING]  
> This is a demo/prototype application. It is under development and intended for demonstration purposes.

## Functionalities

- **Data import**: Upload cycling activity files in FIT formats.
- **Session analysis**: Automatically detects and analyzes training intervals.
- **Graphical display**: Shows interactive graphs of altitude, power, and heart rate.

## Technologies
- **Frontend**: AvaloniaUI (multiplatform graphical interface)
- **.NET Core**: Development framework
- **Data analysis**: Custom processes for interval detection
